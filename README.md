# 拾记 · 笔记管理系统（粗略框架）

基于 HBuilderX + uni-app（Vue 3）+ uniCloud 的课程项目起步框架，当前目标平台为 H5 网站。

## 页面
- 首页：精选推荐、最近更新、搜索入口、新建笔记入口
- 笔记仓库：分类筛选、笔记卡片、AI 工具入口
- 共享广场：公开笔记列表、点赞/收藏/关注的交互占位
- 我的：用户资料、收藏、分享管理、导出入口
- 笔记详情与编辑页

## 在 HBuilderX 中运行
1. 选择“文件 → 导入 → 从本地目录导入”，选择本文件夹中的“项目文件”。
2. 运行到浏览器（H5）查看网站框架。
3. 关联 uniCloud 服务空间，并将 `uniCloud-alipay/database/notes.schema.json` 上传到云数据库。
4. 当前前端读的是 `src/data/demo.js` 演示数据；登录、真实增删改查、文件上传和发布接口需要在后续阶段接入。

## 后续实现建议
先建立用户登录与笔记 CRUD 云函数/数据库 API，再接图片上传、分享权限与撤销发布；AI 整理、润色、思维导图和 OCR 均预留为可选模块。本项目没有接入 AI，也没有真实云端写入，避免演示时误以为数据已保存。
